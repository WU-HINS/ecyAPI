随机图片接口json参数文档

通过 URL 参数选择分类，随机返回图片链接，供开发者简易调用并部署在项目中

单条随机

GET

返回指定分类的一条随机图片链接。

/json?pc

全分类随机

GET

从所有已注册分类里随机挑一个，再随机取图；横竖按设备自动。

/@img

多条随机

GET

在分类参数后写数字，返回指定数量的随机图片链接。

/json?pc=3

参数说明

参数说明示例
分类名 多级分类用 / 连接，如 anime/2024。当前可用：{{range .Categories}}{{.}} {{end}} ?pc / ?anime/2024
数量 给分类参数赋数字值，表示返回几条。不填写时默认返回 1 条。 ?pc=3
方向 landscape（横）/ portrait（竖）/ auto（按 User-Agent 自动）。留空为不限方向；该方向没有图片时自动回退全部，不会 404。 ?pc&orientation=portrait

返回示例

{
  "code": 200,
  "category": "pc",
  "count": 1,
  "data": {
    "id": "86.webp",
    "link": "https://example.com/pic/pc/86.webp"
  }
}
