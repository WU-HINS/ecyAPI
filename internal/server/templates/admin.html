缓存与预热

图库页（HTML + 预生成 gzip）与缩略图（?w=）都会落盘缓存。清理后首次访问会重新生成；预热可在低峰期提前做好，避免高峰期现场渲染。

预热是低优先级任务：有请求进来时自动让路（缩略图最多只占一半像素预算、渲染只在空闲时进行），请求空闲后自动继续。

首页文案

保存后立即生效；标语与分享语留空并保存即恢复默认文案。

备案号链接留空时不生成超链接（仅展示文字）；备案号文字保持默认且链接留空时，将回退到默认官方查询链接。

支持少量 HTML 标签：换行 <br>、加粗 <b>/<strong>、 斜体 <i>/<em>、下划线 <u>、删除线 <s>/<del>、 小字 <small>、上下标 <sub>/<sup>、段落 <p>、 行内容器 <span>、代码 <code>、高亮 <mark>、 链接 <a href="...">（自动补 noopener，仅允许 http/https/mailto）。 其余标签一律按纯文本原样显示，不会被解析。
