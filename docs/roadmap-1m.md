## 总目标

| 指标 | 目标值 |
| --- | --- |
| 图片规模 | 100 万张（本地 + 云端） |
| 常驻堆 | ≤ 40 MB |
| RSS | ≤ 90 MB（含可回收页缓存） |
| 随机查询 | p50 < 50 µs |
| 原图暴露 | 不 302 到外部地址（云端走 /@web 代理） |
| 方向判定 | 惰性 + 持久化，不扫全量 |

## 每轮工作约定

1. 进入一轮：先读本文件，确认当前里程碑与验收标准
2. 一轮只做一个里程碑（或一个子步骤），做完跑 `go test ./...`
3. 达标 → 更新本文件「状态/实测」；不达标 → 记录差距与原因，不硬标完成
4. 提交信息带上里程碑编号（如 `feat(index): M2b-1 ...`），便于回溯
5. 每轮结束必须能回答：当前里程碑、实测数字、下一轮第一步
